changelog = 
    0.9.6
        * The exact numeric transform controls (center X/Y, pixel sizes
        X/Y, RMS) moved from the plugin toolbar into the tie points
        panel, on top of the table. A crowded toolbar hides its tail
        behind the >> extension button, so these widgets could be
        invisible on smaller screens; in the panel they are always
        visible. The panel opens automatically with the N-points tool
        and via the toolbar "Tie points panel" button; editing a value
        moves / scales the raster immediately and is undoable
        * The plugin toolbar is now compact (rotation spinbox stays),
        all its buttons fit without overflow
    0.9.5
        * Reverted the two-click picking experiment of 0.9.4: the
          N-points tool is back to the drag interaction of 0.9.3
          (press on a raster feature, drag it to its real location,
          release)
        * NEW: the Undo toolbar button can now revert ANY last action.
        Tie point operations are included - adding a point by drag,
        enabling / disabling a point, deleting point(s), clearing all
        points and loading points from a file: both the tie points and
        the raster placement are restored as they were before
        * The points table is also refreshed when points are removed or
        cleared from the map tool right-click menu
    0.9.3
        * New tie points table dock (like the GCP table of the built-in
          QGIS georeferencer): each point can be enabled / disabled
          (excluded from the fit) or deleted, with live residuals
          (dX, dY, residual). It opens automatically with the N-points
          tool and can be toggled from the toolbar / Raster menu
        * The raster is refitted and redrawn immediately after any change
          of the points (canvas drag, table toggle / delete / clear)
        * .points files now follow the exact QGIS georeferencer format
          (mapX,mapY,pixelX,pixelY,enable,dX,dY,residual); the legacy
          pixel-first format is still read
    0.9.2
        * FIX: TypeError from FreehandRasterGeoreferencerLayer.metadata()
          (upstream override returned a str, which is the QGIS 2 API;
          QGIS 3 expects a QgsLayerMetadata object). Layer information
          now appears in the standard metadata framework, the plugin
          layer properties dialog keeps the textual summary
    0.9.1
        * FIX: plugin failed to load with AttributeError
          (spinBoxRotateValueChangeEvent handler was missing after the
          toolbar refactor; rotation typed in the spinbox applies again)
        * Added a static self-attribute consistency check to the dev
          toolchain to prevent this class of regression
    0.9.0
        * Export directly to Cloud Optimized GeoTIFF (COG), built from the
          original raster through GDAL (any band count / data type is
          preserved). Two modes: north-up (rotation baked into the pixels,
          resampling selectable) or rotation kept in the geotransform
          (ModelTransformation, with automatic tiled-GeoTIFF fallback)
        * Exact numeric control in the toolbar for the raster center (X/Y)
          and pixel sizes (X/Y), in addition to the rotation spinbox
        * New interactive georeferencing tool with an unlimited number of
          tie points (2 points: similarity fit; 3+ points: least-squares
          anisotropic scaled-rotation fit) with live RMS residuals display
        * Tie points are saved in the QGIS project and can be exported /
          imported as .points files (QGIS Georeferencer compatible CSV)
        * The .aux.xml CRS file is not overwritten anymore if it already
          exists
        * Icons are loaded from files: pyrcc5 is not needed anymore, the
          ui_*.py modules are provided prebuilt (pyuic5 optional)
    0.8.3
        * Disable pixel transformation for formats other than TIFF
    0.8.0
        * FIX #32 Correct issue with the toggling of map tools
        * FIX #35 FIX #38 Add some transformation to the raster if type not directly suppoted by Qt
        * FIX #36 Change rotation to allow 3 decimals
        * FIX #39 Support opening of TIFF files with .tifF extension
    0.7.1
        * FIX #30 Added a setTransformContext method to plugin layer
    0.7.0

        * Solved an issue with the rendering of large rasters when rotated and zoomed out
